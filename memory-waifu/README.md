# Memory Waifu - 二次元学习助手

基于间隔重复算法的智能复习系统，用二次元壁纸收集激励你坚持学习！

## 功能特点

- 📚 **间隔重复算法** - SM-2 算法优化记忆效率
- 🎨 **二次元壁纸收集** - 连签解锁精美壁纸
- 🔥 **激励系统** - 积分、等级、连签打卡
- 💾 **数据备份** - 导出/导入防止数据丢失
- 📱 **PWA 支持** - 可安装到手机桌面，离线使用

## 快速开始

1. 访问 `https://你的用户名.github.io/memory-waifu/`
2. 添加到手机桌面
3. 开始添加卡片并复习
4. 坚持打卡解锁壁纸！

## 数据备份

在"统计"页面可以导出备份文件，建议定期备份防止数据丢失。

## 技术栈

- 纯前端 PWA（HTML/CSS/JS）
- IndexedDB 本地存储
- Service Worker 离线支持
- 多源二次元图片 API
